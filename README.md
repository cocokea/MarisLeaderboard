# MarisLeaderboard

MarisLeaderboard is a leaderboard display plugin with a dedicated admin reload path.

## What It Handles

- Leaderboard display command
- Reload support for updated configuration
- Alias commands for faster access

## Requirements

- Paper / Folia 1.21+
- Java 21

## Installation

1. Put the plugin jar in `plugins`.
2. Start the server once.
3. Edit `config.yml`.
4. Restart the server.

## Commands

- `/leaderboard` - Open or display leaderboard data.
- `/lb` - Alias of `/leaderboard`.
- `/marisleaderboard` - Alias of `/leaderboard`.
- `/leaderboard reload` - Reload leaderboard configuration.

## Files

- `config.yml` - Main settings and display configuration.

## Notes

- Use stable placeholder or storage sources if leaderboard values depend on external systems.
